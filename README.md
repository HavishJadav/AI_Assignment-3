# AI_Assignment-3

This project implements and compares various search algorithms across different environments, measuring their perfo
---

## Features

- **Algorithms Implemented**:
  - Minimax
  - alpha-beta pruning

- **Environments Supported**:
  - Slimevolley

- **Performance Analysis**:
  - Tracks reward per run for each algorithm

- **Visualization**:
  - Also contains videos of both the algorithms 

---

## Installation

Ensure you have Python 3.10+ installed. Install required dependencies:

Before running it is recommended to create a virtual environment through:
```bash
python -m venv env
./env/Scripts/activate
```

```bash
pip install -r requirements.txt
```

---

## How to Run

### 1. Run main to get your video results

```bash
python main.py
```
This will run each algorithm on slimevolley environment and store the result videos in videos folder
